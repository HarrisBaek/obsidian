# 1. ROE (Return of Equity)
`내 자본대비 이자율이 얼마인가?`
- 자본 대비 이익율 
- 100억을 가진 회사가 10억을 벌면  10/100 = 0.1 이다.
- 금리가 0~1% 일때, ROE 5%면 매력적인 기업. (금리와 같으면 은행에 넣겠지)

# 2. PER (Price on Earning Ration)
`몇년을 꾸준히 돈을 벌수있을것인가..`
- 즉 기업의 현재 주가가 해당 기업의 1년치 순이익 대비 몇 배로 평가되고 있는지를 나타내는 지표.
(현재 주가 % 주당 순이익 (EPS))
- 즉 PER가 5이면, 현재 주가를 기준으로 5년 동안 수익을 내면 시가총액이 된다.
- PER가 말도 안되게 높은 이유는, 성장률이 엄청나게 좋을꺼라고 예측해서 주가가 오름.

# 3. PBR (Price Book value Ratio)
`이 회사의 비지니스 모델에 대한 평가`
-  시가총액 / 자본
- 비지니스 모델에 대한 가치 평가로 판단(??)

# 4. PEG (Price/ Earnings-to-Growth Ratio)
`성장대비 PER값`
- PER과 기업의 이익 성장률을 결합한 지표
- PEG = PER / 연간 이익 성장률
- PER이 높아도 이익 성장률이 빠르면 PEG값은 낮아질수 있다. 즉 PER이 30이라도 이익 성장률이 30%라면 PEG는 1이 되어 적정 평가로 간주됨. (낮을수록 성장 대비 저평가)

# 5. EPS (Equity Per Shares)
`한주당 얼마를 벌고있냐.`
- 주식 1주로 얼마의 순이익을 내고 있는지 판단하는 지표.
- 주가  =  PER * EPS (예상주가를 계산해 볼수있다.)

# 6. BPS (Book Per Shares)
- 한주당 순 자산의 가치를 말하는것. 
- 즉 회사가 청산할 경우 주주가 받게 되는 자산의 총액.  (주가의 몇프로를 차지하는지 확인)
- 결국 PBR이 높을수록 이건 낮아지것지.

# 7. CFPS (Cash Flow Per Share)
- 현금흐름 / 주식수
- CPS가 높을수록 재정적인 안정상태에 있다는것.

# 8. PCR (Price Cash flow Ratio) 
- 주가 / CPS = (시가총액/주식수) / (현금흐름/주식수)  = 시가총액/현금흐름
- 결국 이 값이 현금흐름이 많다는뜻 -> 안정적이라는 뜻. 

# 9. PSR (Price-Sales Ratio)
- 주가/ 주당 매출액
- 값이 낮으면 저평가, 높으면 고평가
