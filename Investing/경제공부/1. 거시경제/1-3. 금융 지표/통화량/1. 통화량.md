- 한 나라의 경제에서 일정 시점에 유통되는 화폐의 존재량

# 1. 본원 통화 (M0)
- 중앙은행에서 지폐 및 동전등 독점적 권한을 통하여 공급하는 현금 통화
- 아직 유통되지 않고 가지고 있는돈, 0번째 머니(M0)

본원 통화 = 화폐 발행 잔액 + 중앙은행 예치금

# 2. 협의 통화 (M1)
- M0 + 민간이 보유하고있는 수시 입출식 현금과 예금 취급 기관의 결제성 예금의 합계 (결제성 예금-MMF,MMDA)
- 바로 현금화가 가능한 통화 ( 바로 돈빼기 가능. 토스 입출금 통장)

# 3. 광의 통화 (M2)
- 화폐의 거래적인 기능 이외에 가치를 저장하는 수단으로서의 기능까지 포함된 통화
- M1 + 저축성 예금, 시장 금융상품, 금융채, 외화예금(대신 2년 이상 장기 금융상품 제외)
- **즉 광의 통화가 시장에 풀린 돈 (현재의 유동성)**

# 4. 금융기관 유동성 (Lf)
- M2+ 주식, 채권등 유동성 현금
- 이런 통화는 돈이 아니라, 유동성인 (Liquity) 사용
