# 3. 리 밸런싱 전략
- 정기 + 수시 리밸런싱 전략으로 장기화에 대비

## (1) 정기 리밸런싱 
#### 매년 6월, 12월 실행

	Case 1. 주식이 수익 중일때
		: 위험자산 순으로 리밸런싱 실행
		: BTC -> 개별 주식 -> 인덱스 주식

	case 2. 주식이 하락중일때
		: 리밸런싱 하지 않는다. 
		: 최대 4.5년까지 생활 가능


## (2) 수시 리밸런싱 
#### 특정 조건 충족시에 실행

	Case 1. 특정 자산군이 본 가치보다 30%이상 급등
		: 그 자산을 현금 계좌로 이동

	case 2. 총 자산이 5억 단위 증가
		: 자산을 확정하기 위한 전략
		: 현금으로 이동




| 구분      | 주기        | 행동 (Action)                                                                                                                                                |
| ------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 정기 리밸런싱 | (6월, 12월) | "현금 탱크(단기채)가 4.5억보다 줄었는가?"<br><br>**Case 1. 주식이 수익 중 일때**<br>-> 위험자산 순으로 리밸런싱(코인->개별주->인덱스)<br><br>**Case 2. 주식이 하락 중 일때**<br>-> 노 리밸런싱 ( 최대 4.5년 동안 존버가능) |
| 수시 리밸런싱 | 특정 조건 충족  | **조건 1. 특정 자산군이 원래의 가치보다 30% 이상 급등<br>조건 2. 총 자산이 5단위 이상 증가 시 (자산 확정 전략)**                                                                                 |
